# Square One Chess (PFE)

Full project documentation lives in `docs/`.

## Quick start (dev)

### Backend (root)

```bash
npm install
npx prisma generate
npx prisma db push
npm run dev
```

### Frontend (`frontend/`)

```bash
cd frontend
npm install
npm start
```
